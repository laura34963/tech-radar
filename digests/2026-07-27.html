Runtime Enforcement, Not Runtime Advice

Docker 主張 agentic 系統的治理必須落在 runtime 層以強制執行，而非僅止於建議。

Why it matters

這與既有的 container 安全實務同源——seccomp、read-only rootfs、network policy、NetworkPolicy 等機制原封不動就能套用在 agent 執行環境上，不必為 AI 另建一套控制平面。

Recommended action

展開詳細

文章區分兩種做法：在 prompt 或指引中「告訴」agent 不要做什麼，以及在執行環境中讓它「做不到」。後者的三個支柱是隔離（isolation）、政策強制（policy enforcement）與受控的工具存取（controlled tool access），三者都需由沙箱或容器 runtime 提供，而非交由模型自律。
